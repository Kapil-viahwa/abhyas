## Known gaps carried forward

| Gap | Impact | Phase that fixes it |
| --- | --- | --- |
| No Nginx in front of the stack | No TLS termination, static-asset serving or edge rate limiting; TLS ends at whatever proxy the operator puts in front | Hardening phase |
| No object storage | Question media cannot be uploaded or served; `media_assets` is design only | Phase 4 |
| Containers run as root | A container escape starts privileged; no `USER` directive in the images | Hardening phase |
| Images copy the whole workspace | Each image carries every package and dev tooling: slow pulls, larger surface | Hardening phase (pruned `pnpm deploy`) |
| SMTP delivery is a stub | `EMAIL_PROVIDER=smtp` requires `SMTP_URL` and boots, but the transport throws instead of sending, so verification and reset mail is not delivered in production | Before the platform goes live (decision 0027) |
| Mobile OTP sign-up and sign-in | Students register with an email address and a password only; there is no SMS flow, and the `SMS_PROVIDER` seam is wired but unused | Phase 2c |
| The Content-Security-Policy allows `'unsafe-inline'` for scripts | Next's bootstrap script is inline, so the policy cannot be nonce-based yet and blocks less of an injected script than it otherwise would | Hardening phase, with the edge proxy |
| Dev-only advisories | `vitest`/`tinypool` and the `eslint` chain, tracked in `docs/security-exceptions.md` | Continuous, via Dependabot |
